# Password Generator Userscript

Userscript-версия текущего расширения Password Generator для Tampermonkey, Violentmonkey и совместимых менеджеров.

## Установка

1. Откройте файл `password-generator.user.js`.
2. Установите его через Tampermonkey или Violentmonkey как новый userscript.
3. Откройте любой сайт и нажмите плавающую кнопку `PG` справа снизу.

## Поведение

- Встроенного дефолтного мастер-ключа нет. При первом запуске поле пустое.
- Плавающая кнопка использует inline-SVG, встроенный прямо в userscript; внешних PNG/SVG/URL-иконок нет.
- Плавающую кнопку можно перетаскивать мышью или touch-жестом; позиция сохраняется между открытиями страниц.
- Домен берется из текущего URL, но поле редактируемое.
- В компактной панели есть быстрый выбор длины `24` или `16`; это меняет обычный параметр длины и сохраняется для домена.
- Настройки сохраняются через `GM_getValue` / `GM_setValue`; если менеджер их не дает, используется `localStorage`.
- После генерации сохраняются настройки для текущего домена и последние глобальные значения для новых сайтов.
- Если включить `Не запоминать мастер-ключ`, мастер-ключ не сохраняется ни для домена, ни как последнее глобальное значение.
- Алгоритм генерации сохранен совместимым с текущим расширением: PBKDF2-HMAC-SHA-256, 300000 итераций, соль `pw:<domain>|v=<version>|c=<counter>`.
- Для обновлений используются metadata-поля `@updateURL` и `@downloadURL`, указывающие на asset `password-generator.user.js` в последнем GitHub Release. Автообновление выполняет Tampermonkey/Violentmonkey согласно своим настройкам проверки обновлений.
